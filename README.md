# D43m0n4RcH7 Personal Website

Personal portfolio website for D43m0n4RcH7, a full-stack developer focused on automation systems, Twitch and Discord moderation bots, Linux infrastructure, and proxy technologies.

## Overview

The site presents a compact developer profile with:

- responsive terminal-inspired glassmorphism layout;
- animated professional focus line;
- technology stack overview;
- GitHub profile link;
- direct email contact;

## Tech Stack

- HTML5
- TypeScript
- CSS with Tailwind CSS utilities
- Vite
- JetBrains Mono
- Font Awesome

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run the production checks:

```bash
npm run build
npm run lint
```

Preview the production build:

```bash
npm run preview
```

Build the production version with:

```bash
npm run build
```
